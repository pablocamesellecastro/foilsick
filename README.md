# Foilsick Store

Tienda online de soluciones de diseño de sonido, built with Next.js, Supabase y Tailwind.

## Stack

- Next.js 14
- Supabase (base de datos + auth)
- Tailwind CSS

## Funcionalidades

- Catálogo de productos
- Carrito de compra
- Autenticación de usuarios
- Pasarela de pago
- Gestión de inventario
- Experiencia elegante y minimalista

## Cómo ejecutarlo en local

1. Clona el repo
2. Instala dependencias: `npm install`
3. Crea un `.env.local` con las variables necesarias
4. Ejecuta: `npm run dev`
5. Abre http://localhost:4700
